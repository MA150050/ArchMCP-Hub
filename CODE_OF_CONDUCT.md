# Code of Conduct

As the creator and maintainer of **ArchMCP Hub**, **Mohamed Abd El-Hafez** is committed to providing a respectful, constructive, and harassment-free environment for everyone participating in this repository's issue tracker and discussions.

- Communicate respectfully and provide accurate, reproducible technical details when reporting issues.
- Respect intellectual property rights and upstream open-source licenses ([`LICENSE`](LICENSE) and [`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md)).
- Never publish API keys, access tokens, passwords, or private configuration data in issues or pull requests.
