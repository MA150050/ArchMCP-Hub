# Pre-Release Private Development Notes (`1.1.4` – `1.2.0`)

The files in this directory are **internal engineering and debugging logs** recorded during private development prior to the **first official public release (`ArchMCP Hub v1.0.0`)**.

- **No version prior to `v1.0.0` was ever published as an official public release.**
- All capabilities and fixes documented in these pre-release notes (`RELEASE-NOTES-1.1.4.md` through `RELEASE-NOTES-1.2.0.md`) are consolidated into **ArchMCP Hub v1.0.0** (see [`../../CHANGELOG.md`](../../CHANGELOG.md)).
