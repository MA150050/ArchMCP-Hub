# ArchMCP Hub v1.0.0 — Official Public Release Notes

**ArchMCP Hub v1.0.0** is the first official public release of the local-first Windows desktop control center for installing, managing, repairing, disabling/uninstalling, and verifying **Model Context Protocol (MCP)** integrations across architectural, BIM, and 3D CAD applications.

## Highlights of v1.0.0

- **5 Supported Engineering Hosts**: **Autodesk Revit (2022–2027)**, **Rhinoceros 3D (Rhino 7 & Rhino 8)**, **Autodesk 3ds Max (2021–2027)**, **Autodesk AutoCAD (2021–2027)**, and **SketchUp (2021–2026)**.
- **5 Supported AI Clients**: **OpenCode**, **Claude Desktop** (including 3.x MSIX `Claude-Data`), **Claude Code**, **OpenAI Codex**, and **Google Antigravity** (including `.venv-modern` MCP SDK 2.x shim for `2026-07-28` `server/discover`).
- **Complete Lifecycle Actions**: **Install & connect**, **Disable / Uninstall**, **Repair**, and **Verify** with automatic timestamped `.backup-YYYYMMDD-HHMMSS` snapshots and rollback.
- **Official Brand Identity**: Integrated multi-resolution `ArchMCP.ico` (`16x16` to `256x256`), `ArchMCP.png`, and SVG architecture/workflow diagrams.
